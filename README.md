# Bangla Disease Prediction using BanglaBERT

This project presents a deep learning based system for predicting diseases from Bangla symptom descriptions. The dataset contains 24 diseases and 1200 symptom samples which were augmented to improve model generalization. A stratified train/validation/test split was used along with data leakage prevention techniques.

The model is built using BanglaBERT with partial fine-tuning of the last transformer layers. The system achieved strong performance with high accuracy and F1-score on the test dataset.

This project was developed as part of a thesis on Bangla medical text classification.
